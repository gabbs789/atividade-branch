# Atividade de Branches e Pull Requests

Este repositório foi criado para cumprir os requisitos:

- Adicionar 5 funcionalidades
- Criar uma branch separada para cada nova funcionalidade
- Cada funcionalidade deve ter no mínimo 2 commits por branch
- O nome do branch deve seguir o padrão `feature/nome-da-funcionalidade`
- Fazer 2 merge direto no `master`
- Fazer 3 pull-requests no `master`

Funcionalidades planejadas (nomes dos branches):
- feature/cabecalho
- feature/rodape
- feature/contato
- feature/sobre
- feature/faq

A estrutura de arquivos é propositalmente simples para facilitar a criação de branches e commits rápidos.
